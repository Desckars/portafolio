Este repositorio contiene alguno de los proyectos realizdos a lo largo de la carrera Tecnologo en Informatica de UTEC.
Cada proyecto contiene un README los cuales contienen datos como:
- Introduccion al proyecto
- Programas requeridos
- Ambiente de prueba (Linux o Windows)
- Pasos para ejecutarlo

Cada proyecto fue realizado en un plazo de 4 meses, con un equipo de minimo 2 y maximo 4 integrantes.
