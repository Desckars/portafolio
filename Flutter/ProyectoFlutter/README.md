Descripcion
Necesitamos crear una aplicación Movil para la gestión de un Hostel.
Es una aplicacion “ad hoc” para el hostel “Mochileros”, esto quiere decir que no va a haber mas de
un hostel a gestionar. Existen dos tipos de usaurios: admin y huesped, cuyas funcionalidades se
detallan en los requerimientos funcionales.
Es una arquitectura distribuida donde la persistencia y/o Backend se llevará a cabo en un servidor
externo

Base de dato: MongoDB
Nombre de la BD: App_Movil
Programa para usado para las pruebas: Android Studio
Comandos para ejecutar proyecto:
flutter doctor
dart run
